# Abstract Drafts

## Draft 1 (Empirical focus)

When autoregressive language models process sequences containing repeated key-value updates, they reliably retrieve the first value (retroactive interference, RI) but systematically fail at retrieving the last value (proactive interference, PI). We present a cross-architecture mechanistic investigation of this PI > RI asymmetry across 9 models spanning transformers and state-space models. Using logit lens analysis, we show that the correct last value IS computed at intermediate layers but gets outcompeted by adjacent values in the final layers. Probing classifiers reveal that RI success is well-encoded in the residual stream (87% probe accuracy) while PI success is representationally indistinguishable from PI failure (61%, near chance). Crucially, the Mamba SSM — which lacks causal attention, softmax, and positional encoding — shows the same PI > RI pattern (gap = +57%), eliminating these as sole causes. Jacobian analysis at initialization reveals that the primacy bias is architectural: present in random-weight models (1.47x for transformers, 295x for SSMs). We identify three architecture-dependent error modes (recency imprecision, primacy fallback, off-by-one lock) and show PI accuracy decays exponentially with the number of updates while RI remains robust. A preliminary bidirectional control (Flan-T5) shows no PI > RI, supporting autoregressive encoding as the key factor. Our results establish that PI > RI is an inherent property of sequential processing with continuous gating and fixed-capacity state, not a fixable bug in a few attention heads.

## Draft 2 (Theory + empirical)

Autoregressive language models exhibit a systematic retrieval asymmetry: given a sequence of key-value updates, they reliably recall the first value (RI) but fail at the last (PI). We provide cross-architecture mechanistic evidence explaining why. Across 9 models from 7 architecture families — including Mamba SSMs that lack attention entirely — we find PI > RI in 91% of conditions (mean gap: 50 percentage points). We show this asymmetry is architectural, not learned: Jacobian analysis at initialization reveals primacy bias in untrained models (1.47x in transformers, 295x in SSMs). Logit lens analysis shows the last value is found at intermediate layers but outcompeted in the final layers, while first-value retrieval is clean and monotonic. Probing classifiers demonstrate the asymmetry exists in representation space: RI correctness is well-encoded (87%) but PI correctness is indistinguishable from failure (61%). Our cross-architecture comparison eliminates causal attention, softmax, and RoPE as sole causes, narrowing the mechanism to the combination of autoregressive processing, continuous gating, and fixed-capacity state. We derive bounds showing PI accuracy decays as O(exp(-bN)) while RI scales with model depth, and identify three architecture-dependent error modes. These findings demonstrate that PI > RI is a fundamental property of sequential processing, not an emergent behavior fixable by scaling.

## Draft 3 (Shortest, most punchy)

Language models remember first and forget last. We show this is architectural. Across 9 models including Mamba SSMs (no attention), 91% of test conditions show first-value retrieval dominating last-value retrieval by 50 percentage points. The asymmetry exists at initialization (Jacobian: 1.47x primacy in transformers, 295x in SSMs), in representations (probing: 87% vs 61% correctness encoding), and in intermediate computations (logit lens: correct value found then suppressed). We eliminate causal attention, softmax, and positional encoding as sole causes, narrowing the mechanism to autoregressive processing with continuous gating. PI accuracy decays exponentially with update count while RI remains robust — this is a fundamental limit of sequential processing, not a fixable bug.
