\title{First Value, Not Latest: How Language Models Fail at\\Sequential Key-Value Update Tracking}

\author{Anonymous}

% ============================================================
\begin{abstract}
We study sequential update tracking in interleaved streams: given a
randomly interleaved stream in which $K$ keys each receive $N$ updates, can a language model retrieve the current value of a target key while competing keys are interspersed throughout?
Across 20 models spanning 14 open-weight checkpoints (270M--9B parameters) and six proprietary frontier models, we find a robust asymmetry: accuracy on current-value queries (CVQ) is systematically lower than on first-value queries (FVQ), and the asymmetry persists across model scale and family.
This failure is format-conditioned: adding explicit structural cues to the same content substantially reduces or eliminates the gap, while plain interleaved streams fail consistently.
Our results indicate that language models apply format-conditioned retrieval heuristics over update streams rather than maintaining internal state, with direct implications for how sequential-update tasks are designed and evaluated.
\end{abstract}

% ============================================================
\section{Introduction}
\label{sec:intro}
% ============================================================

Language models are now deployed in settings that require tracking
which value is currently assigned to an entity as it changes over time:
multi-turn assistants where users correct facts mid-conversation,
retrieval-augmented pipelines where documents may reflect outdated
state, and tool-augmented agents where successive API calls update the
same variable.
\citet{laban2025multiturn} show that multi-turn dialogues cause
substantial performance degradation as state updates cascade and
contradict earlier context.
These failures share a common structure: a model that anchors to an
earlier value and fails to incorporate subsequent updates.

Prior work on entity state tracking \citep{kim2023entity,kim2024code}
tests models on single-entity sequential transitions --- one object
moved between locations --- without competing entities simultaneously
present in the stream.
\citet{unable2forget2025} demonstrate KV interference within context
but frame it as a fundamental architectural limit.
Critically, neither line of work examines the cross-key competition
that characterises real multi-entity tracking: multiple entities whose
updates are interleaved throughout the stream, each potentially masking
the others.
\citet{lostinthemiddle} and long-context benchmarks such as RULER
\citep{ruler2024} and HELMET \citep{helmet2024} test whether models can
retrieve static facts from noise --- not whether they can identify
which update to a repeatedly-modified key is current.

We study this gap directly: given a randomly interleaved stream of
$K$ keys each updated $N$ times, can a model retrieve the current
value of a target key while competing keys are interspersed throughout
(Figure~\ref{fig:task})?
Across 15 models spanning 270M to 9B parameters, we find a robust
asymmetry between first-value and current-value accuracy across all
tested models and scales, and show the failure is format-conditioned:
explicit structural cues and narrative format substantially restore
performance while plain streams fail consistently.

We make the following contributions:
\begin{itemize}
\item A systematic study of sequential update tracking across 20
  open-weight and proprietary models on a controlled $K \times N$
  grid, establishing a robust FVQ/CVQ asymmetry across transformer
  families and scales; results on Arbitrary-Single confirming the
  pattern are in the appendix (\S\ref{sec:results}).

\item A format ablation showing the asymmetry is format-conditioned:
  explicit structural markers and narrative format substantially reduce
  or eliminate the gap, while plain interleaved streams fail
  consistently (\S\ref{sec:format}).

\item A positional analysis showing that models can track only the
  first few positions in plain update streams before accuracy collapses,
  indicating a structural enumeration deficit rather than a
  recency-specific limitation (\S\ref{sec:positional}).

\item A mechanistic analysis using probing classifiers and logit lens,
  revealing that CVQ correctness is not reliably encoded in final-layer
  representations, and identifying two distinct internal failure modes:
  \textit{first-value anchoring} --- the first value dominates all
  layers from the outset --- and \textit{transient suppression} ---
  the correct current value briefly surfaces at intermediate layers
  but is suppressed before output (\S\ref{sec:analysis}).

\item A training-dynamics analysis across 82 checkpoints from two
  model families --- 42 pretraining checkpoints of SmolLM2-1.7B and
  40 SmolLM3-3B checkpoints spanning three pretraining stages and
  four post-training stages (mid-training, SFT, expert specialisation,
  alignment soup) --- showing the asymmetry is present at the earliest
  pretraining checkpoint of both models, persists through every
  subsequent training step, and survives every post-training stage
  including the final released model
  (\S\ref{sec:analysis}, Appendix~\ref{app:training}).
\end{itemize}

\section{Related Work}
\label{sec:related}
% ============================================================

\paragraph{Sequential state tracking.}
Early work established entity state tracking as a hard problem for
language models: \citet{babi2015} used synthetic narratives and
\citet{propara2018} used procedural text.
\citet{kim2023entity} found that only GPT-3.5 could track entity state
in programmatic transition sequences, attributing this to code
pretraining \citep{kim2024code}.
These works evaluate only final-state accuracy using action-verb prose;
none study the asymmetry between first-value and current-value
retrieval, nor plain interleaved streams with multiple competing keys.

\paragraph{KV update tracking.}
Most directly related, \citet{unable2forget2025} study a KV update
setting where 46 keys each receive up to 400 updates, finding retrieval
accuracy declines log-linearly as updates accumulate.
They also test format interventions --- natural language annotations
marking prior values as outdated --- and find minimal improvement,
concluding the failure is fundamental.
Our work differs in three ways: we test both first-value and
current-value queries, revealing an asymmetry their single-query
design cannot observe; we apply structural format interventions
(positional labels and round markers) rather than semantic annotations,
and find these substantially restore performance; and we vary key
count $K$ systematically, identifying it as the primary driver
of failure.

\paragraph{Long-context retrieval.}
\citet{lostinthemiddle} show that models exhibit a U-shaped accuracy
curve in long contexts, reliably accessing information near the
beginning and end but failing at mid-context positions.
\citet{ruler2024} introduce a variable-tracking sub-task where a value
$V$ is assigned to $X_1$, followed by a chain of bindings
($X_2{=}X_1$, $X_3{=}X_2$, \ldots) embedded in noisy filler text;
each variable is assigned \textit{once}, and the model must identify
all variables pointing to $V$.
Our task differs from both: we test repeated destructive updates to
the \textit{same} key interleaved with competing keys, and our failure
scales with the number of competing keys rather than context length
or chain depth.

\paragraph{Format sensitivity and theoretical limits.}
\citet{sclar2024} show that meaning-preserving changes to prompt
formatting cause accuracy swings of up to 76 percentage points; our
format ablation is a controlled instance of this, holding stream
content constant while varying only its positional structure.
\citet{fagnou2024} prove that tracking compositional entity chains ---
where each state depends on the prior --- requires
$\lceil \log_2(n{+}1) \rceil$ transformer layers; our task involves
independent destructive updates with no dependency chain, so this
depth constraint does not apply.
\citet{hahn2020} shows that softmax attention dilutes the influence of
any single token as sequence length grows, and \citet{merrill2023}
proves that fixed-depth transformers are bounded by first-order logic
with majority quantifiers: in a plain interleaved stream where all
entries for a key are structurally identical, attention over those
entries disperses rather than concentrating on the most recent one.
Our format interventions are consistent with this: explicit positional
labels give each entry a unique token signature, allowing attention to
concentrate on the correct position and converting implicit sequential
tracking into an explicit lookup.
\citet{li2025state} apply linear probes and activation patching to
models trained on permutation composition, identifying two interpretable
tracking algorithms in models that \emph{succeed} at the task.
We apply the same toolkit to models that \emph{fail} at destructive
key-value update tracking---a direction prior work leaves unaddressed---and
identify two distinct failure modes across model families.

\section{Task and Experimental Setup}
\label{sec:setup}
% ============================================================

\subsection{Task Definition}

We define \textbf{Sequential Update Tracking under Interference} (SUTI):
given an interleaved stream of key-value pairs in which $K$ keys each
receive $N$ updates, retrieve the current (most-recently assigned) value
of a designated target key.

Formally, let $\mathcal{K} = \{k_1, \ldots, k_K\}$ be a set of keys and
let $V_i = (v_{i,1}, \ldots, v_{i,N})$ be the ordered update sequence for
key $k_i$.
The input stream $\sigma$ is a randomly interleaved permutation of all
$K \times N$ pairs $\{(k_i, v_{i,j})\}$, subject to the constraint that
no two consecutive entries share the same key.
The model receives $\sigma$ and a target key $k_t$, and is asked one of
two queries:

\begin{itemize}
  \item \textbf{FVQ} (first-value query): \textit{``What was the first value of $k_t$?''}
        $\rightarrow$ expected answer $v_{t,1}$
  \item \textbf{CVQ} (current-value query): \textit{``What is the current value of $k_t$?''}
        $\rightarrow$ expected answer $v_{t,N}$
\end{itemize}

\noindent
Figure~\ref{fig:task} illustrates the structure for $K=3$, $N=3$.
The stream contains $K \times N = 9$ entries; the correct CVQ answer for
\textit{color} is \textit{green} (its third update).
We call $K$ the \textbf{key count} and $N$ the
\textbf{update depth}.
The two dimensions are confounded with stream length ($K \times N$ total
entries); we address this in Section~\ref{sec:results}.

\subsection{Stream Formats}
\label{sec:formats}

We evaluate three prompt formats applied to the same underlying stream
content (Figure~\ref{fig:formats}):

\paragraph{Plain stream.}
Key-value pairs are written as \texttt{key: value}, one per line,
randomly interleaved. No positional markers are present.
This is the primary format for our behavioral sweep.

\paragraph{Labeled stream.}
Each entry is annotated with an explicit update counter inline:
\texttt{key (update $j$): value}. The model can identify any
specific update by its label without enumerating the stream.

\paragraph{Block stream.}
All $K$ keys are grouped together per round under a
\texttt{[Round $j$]} header. Updates are not individually labeled
but round boundaries are explicit.

\noindent
We use these formats in Section~\ref{sec:format} to test whether
CVQ failure is format-conditioned.
The plain stream is the failure condition; labeled and block streams
test whether externalising positional structure restores performance.

\subsection{Datasets}

We evaluate on two stream formats: a structured \textbf{key--value list},
used for the main grid and mechanistic analysis, and a natural-language
\textbf{narrative}, used for the format intervention in
\S\ref{sec:format}.
The key--value variant uses 46 semantic categories
(e.g., \textit{color}, \textit{fruit}, \textit{metal}) following the
protocol of \citet{unable2forget2025}; the narrative variant is a
Dota~2 match commentary dataset in which heroes act as keys and
attribute updates (gold, kills, \ldots) act as values woven into
match prose. The mechanistic analysis in \S\ref{sec:analysis} uses a
single-token variant of the key--value format to make activation
patching tractable. Full construction details for both formats appear
in Appendix~\ref{app:datasets}.

\subsection{Experimental Grid}

We evaluate all models on a unified grid:
\[
K \in \{2, 3, 5, 7, 10, 15, 20, 25, 30\}, \quad
N \in \{5, 7, 10, 15, 20, 30, 50, 75, 100\}
\]
with up to 200 trials per $(K, N)$ cell per query type (FVQ and CVQ).
Cells excluded for context-length or pool-size reasons are detailed
in Appendix~\ref{app:datasets}.

\subsection{Models}

We evaluate 14 open-weight models (270M--9B parameters) spanning
Qwen2.5, Qwen3.5, Gemma-3, and three LLaMA-style models
(TinyLlama-1.1B, StableLM-2-1.6B, Pythia-410M), together with six
proprietary frontier models.
For the figures and mechanistic analysis in the main text we focus
on two models from different families,
\textbf{Qwen2.5-3B-Instruct} and \textbf{Gemma-3-4b-it}, chosen for
their distinct failure shapes (\S\ref{sec:results}).
Cross-model breadth on Semantic-Multi appears in
Table~\ref{tab:main_results}; the full per-model grid and
Arbitrary-Single replication are deferred to
Appendices~\ref{app:full_results} and~\ref{app:arb}.

\subsection{Evaluation}

For each $(K, N)$ cell, we report FVQ accuracy and CVQ accuracy as
exact-match proportions, with Wilson score 95\% confidence intervals
\citep{wilson1927}.
The primary metric is the \textbf{gap}: $\Delta = \text{FVQ} - \text{CVQ}$.
A positive gap indicates FVQ dominance (the failure mode we study);
a negative gap indicates CVQ dominance.
All inferences use greedy decoding (temperature~0) to eliminate
sampling variance.

\section{The FVQ--CVQ Asymmetry}
\label{sec:results}
% ============================================================

Every model we evaluate is more accurate at recovering the
\emph{first} value bound to a key than the \emph{current} value, on at
least one $(K, N)$ cell of our grid.
Figure~\ref{fig:main_results} shows the shape of the failure for
two representative open-weight models, and
Table~\ref{tab:main_results} reports a representative cross-model
summary on Semantic-Multi.

\paragraph{Shape of the failure.}
Figure~\ref{fig:main_results} traces FVQ and CVQ accuracy along two
axes of the grid for Qwen2.5-3B-Instruct and Gemma-3-4b-it.
In Gemma-3-4b-it FVQ tracks ceiling while CVQ degrades monotonically
in both $K$ (number of competing keys) and $N$ (updates per key) ---
the canonical asymmetric pattern.
In Qwen2.5-3B-Instruct both FVQ and CVQ degrade, but CVQ degrades
faster and stays below FVQ throughout the scanned region.
The asymmetry is therefore not a single phenomenon: in some models it
takes the form of a failure to overwrite a stable first binding, in
others a faster loss of the most recent binding under load.

\paragraph{Cross-model breadth.}
Table~\ref{tab:main_results} reports the asymmetry across twelve
models on Semantic-Multi.
Because the cell at which a model first exhibits a measurable gap
depends on scale, we report each block at the smallest $(K, N)$ where
every model in that block shows gap $> +0.05$: $K{=}20, N{=}50$ for
proprietary models, $K{=}5, N{=}30$ for open-weight models.
Scale shifts the failure regime --- proprietary models hold the
ceiling on cells where open-weight models already collapse --- but
does not eliminate the asymmetry.

The behavioural asymmetry shown above motivates the rest of the paper.
\S\ref{sec:positional} examines whether the failure is positional ---
which entries within a key's update sequence the model can and cannot
recover.
\S\ref{sec:format} shows that structural format changes (positional
labels, round blocks) substantially close the gap without changing
the underlying content, indicating the failure is format-conditioned
rather than informational.
\S\ref{sec:analysis} identifies the internal mechanism: a specific
cluster of attention heads in the upper-middle layers carries the
FVQ--CVQ distinction in both Qwen2.5-3B-Instruct and Gemma-3-4b-it,
and the asymmetric magnitudes of their primacy and recency boosts
predict the behavioural asymmetry observed here.
Full per-model $(K, N)$ grids and results on the controlled
Arbitrary-Single (ARB) dataset --- which qualitatively replicates the
SEM patterns --- appear in Appendices~\ref{app:full_results}
and~\ref{app:arb}.

\subsection{Training dynamics}
\label{sec:analysis:training}

To rule out the asymmetry being an artifact of alignment, supervised
fine-tuning, or any single training step, we track the FVQ$-$CVQ gap
across 82 checkpoints from two model families:
42 pretraining checkpoints of SmolLM2-1.7B
\citep[step 125k through the released final model;
][]{allal2025smollm2} and 40 SmolLM3-3B checkpoints spanning three
pretraining stages and four post-training stages
\citep[mid-training, SFT, expert specialisation, alignment soup;
][]{smollm3}.
At each checkpoint we evaluate on Arbitrary-Single at
$K \in \{2, 3, 5, 7\}, N \in \{2, 3, 5, 7, 10, 15, 20, 30\}$
(100 trials/cell, completion format throughout to avoid
chat-template artifacts at early IT checkpoints; see
Appendix~\ref{app:training}).

Figure~\ref{fig:training_dynamics} reports the mean gap at each
checkpoint, partitioned into two regimes that show qualitatively
different trajectories.
For \textbf{low-load cells} ($K \leq 3$; mean over 16 cells per
checkpoint), the gap is positive at the earliest available
checkpoint in both models and stays positive across the entire
trajectory --- the primacy regime.
For \textbf{high-load cells} ($K \geq 5$ and $N \geq 20$; mean over
4 cells per checkpoint), the gap is \emph{negative} at the earliest
checkpoint in both models and stays negative across the entire
trajectory --- the recency regime, in which CVQ accuracy exceeds FVQ.

The reversal we noted in \S\ref{sec:results} for Qwen-family models
at high $(K, N)$ is therefore not an idiosyncrasy: the same regime
flip is established within the first 40k--125k pretraining steps of
both SmolLM2 and SmolLM3, persists through every pretraining stage,
and survives every SmolLM3 post-training stage including the final
released model.
The bias is regime-dependent, not unidirectional, and it is not
introduced by any single training stage.

\section*{Limitations}
% ============================================================

\paragraph{$K$ and context length are confounded.} The total stream
length grows as $K \times N$, so increases in $K$ at fixed $N$
co-vary with overall context length.
We do not separate the contribution of key count from context length:
doing so would require holding $K \times N$ constant and varying the
$K/N$ ratio, which we leave for future work.

\section{Dataset Details}
\label{app:datasets}
% ============================================================

We construct three datasets, varying the surface form of the update
stream while holding the underlying $(K, N)$ structure fixed.
The two key--value variants (ARB and SEM) share schema and grid; the
narrative variant (NAR) tests the same task in prose.

\paragraph{Arbitrary-Single (ARB).}
A pool of 2,300 single-token English words organized into 46 semantic
categories (e.g., \textit{color}, \textit{fruit}, \textit{metal}).
For each trial, $K$ categories are sampled as keys and $N$ values are
drawn without replacement from each category's pool.
Keys and values share no inherent update semantics --- there is no
reason to expect any particular ordering among values of the same
category. This isolates tracking from semantic shortcuts and provides
the single-token values required for the mechanistic analysis
(\S\ref{sec:analysis}).

\paragraph{Semantic-Multi (SEM).}
A pool of 2{,}403 multi-token values across the same 46 categories,
where values are real members of each category
(e.g., \textit{gemstone} $\rightarrow$ \textit{alexandrite},
\textit{amethyst}, \ldots).
Values are multi-token and drawn from a smaller per-category pool
(45--70 values), limiting feasible update counts to $N \leq 50$ for
most key counts.
SEM is the primary behavioural dataset because the realistic
key--value semantics rule out trivial template-matching strategies.

\paragraph{Narrative (NAR).}
Inspired by \citet{kim2023entity}, who embedded entity state updates
in programmatic English sequences, we test whether the same tracking
task becomes easier when updates appear in natural prose.
We use a Dota~2 match commentary dataset in which $K$ game entities
(heroes) each have $N$ attribute updates (e.g., gold, kills) woven
into match narration; FVQ and CVQ queries ask for the first and
current attribute value of a target hero.

\paragraph{Grid coverage.}
On the unified grid $K \in \{2, 3, 5, 7, 10, 15, 20, 25, 30\}$,
$N \in \{5, 7, 10, 15, 20, 30, 50, 75, 100\}$ (\S\ref{sec:setup}),
cells where the prompt exceeds a model's context limit are excluded;
cells where the dataset pool is insufficient are also excluded
(relevant for SEM at high $N$).
This yields up to 79 feasible cells per model on ARB and up to 63 on
SEM.

\section{Arbitrary-Single Replication}
\label{app:arb}
% ============================================================

The Semantic-Multi dataset uses real category members as values, so
trivial template matching cannot solve the task; the Arbitrary-Single
(ARB) dataset replaces these with single-token words drawn from the
same 46 categories, removing semantic coherence between key and
value.
ARB is also the dataset used for the mechanistic analysis
(\S\ref{sec:analysis}) because single-token values are required for
activation patching.
Table~\ref{tab:full_arb} reports the gap on ARB at the same four
$(K, N)$ cells as Table~\ref{tab:full_sem}.

The qualitative pattern matches: gap $> 0$ for the great majority of
cells, with the same three models (Qwen2.5-3B-Instruct, Qwen2.5-3B
base, Qwen3.5-4B) crossing into reversal at large $(K, N)$.
Absolute gap magnitudes are within $\pm$0.1 of their SEM counterparts
in 9 of 12 fully-populated rows, supporting our reliance on ARB for
mechanistic analysis: the failure mode visible mechanistically on
single-token values is the same failure mode visible behaviourally on
realistic multi-token values.

\section{Format Intervention Data}
\label{app:formats}
% ============================================================

This appendix reports raw format-intervention data used by
\S\ref{sec:format}. We test four prompt formats applied to the same
underlying stream content on the Semantic-Multi dataset at
$K{=}10, N{=}50$ --- the hardest cell available in the format sweep
($K \in \{5, 10\}$, $N \in \{10, 20, 50\}$).
Up to 200 trials per (model, format) cell.

\paragraph{Formats.}
\textbf{Plain} (\texttt{flat\_nolabel}) is the default condition used
elsewhere in the paper: \texttt{key: value}, one per line, no
positional markers.
\textbf{Labeled} (\texttt{flat\_verbose}) tags each entry with an
explicit update index: \texttt{key (update $j$): value}.
\textbf{Block} groups all $K$ keys per round under a
\texttt{[Update $j$]} header (no per-entry labels).
\textbf{Landmark} uses the block layout but separates rounds with a
\texttt{---} delimiter and no round number, so round boundaries are
visually explicit without a numeric anchor.

\paragraph{Gap reduction (Table~\ref{tab:format_gap}).}
Both explicit-label formats collapse the FVQ$-$CVQ gap toward zero
for open-weight models: Plain-format gaps of $+0.27$ to $+0.99$
become $\pm 0.10$ under Labeled or Block.
Proprietary models start with a smaller Plain-format gap (mostly
$\le +0.31$, with Claude-4.5-Haiku at $+0.56$) but follow the same
direction.
The Landmark format --- which removes numeric labels but keeps round
boundaries visible --- helps the proprietary models reach near-zero
gap but does not help Gemma-3-4b-it ($+0.92$) or Qwen3.5 models
($+0.52$ to $+0.73$), suggesting that explicit per-update tokens
(not just round structure) are what restores CVQ in the open-weight
group.

\begin{table*}[h]
\centering
\small
\input{figures/tab_format_gap.tex}
\caption{FVQ$-$CVQ gap by format on Semantic-Multi at
$K{=}10, N{=}50$. Up to 200 trials per (model, format) cell.
A gap near zero indicates the format intervention has equalised
first-position and last-position retrieval; large positive gap means
the asymmetry persists. Qwen3.5-9B runs incomplete.}
\label{tab:format_gap}
\end{table*}

\paragraph{Absolute CVQ accuracy (Table~\ref{tab:format_cvq}).}
The gap reduction is driven by CVQ rising under labelled formats, not
by FVQ falling: under Plain, open-weight CVQ accuracy is $\le 0.23$
for all four reported models; under Block it rises to $\ge 0.89$ in
every case. Labeled gives a similar lift for three of four
open-weight models (Qwen3.5-2B/4B, Qwen2.5-3B-Instruct, and to a
lesser extent Gemma-3-4b-it at 0.47).
This rules out the alternative explanation that the formats simply
confuse the model into uniform random output.

$K \in \{2, 3, 5, 7\}, N \in \{2, 3, 5, 7, 10, 15, 20, 30\}$ (32 cells)

chat template returns near-zero accuracy on early

checkpoint.
The gap is positive at every checkpoint; it rises sharply through
mid-pretraining (peaking at step 625{,}000) and partially collapses
late in pretraining before stabilising around $+0.25$.
